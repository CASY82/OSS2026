# NL2SQL 500문항 확장 평가 결과

## 테스트 범위와 방법

이번 평가는 `nl2sql_extended_questions.json`의 500문항을 사용해 OSS2026에 이식된 `src/nl2sql`을 검증했다.

- 모델: `gemma4:e4b` (`temperature=0`)
- 데이터베이스: Company-X PostgreSQL
- 평가 방식: 실행 정확도(Execution Accuracy, EX)
- 실제 SQL: 자연어 질문을 OSS2026의 `nl2sql.answer()`에 전달해 생성·검증·실행
- 기대 SQL: fixture의 `expected_sql`을 같은 데이터베이스에서 실행
- 판정: 실제 결과 행과 기대 결과 행 비교
- 정렬: 기대 SQL에 `ORDER BY`가 있으면 순서를 포함해 비교하고, 없으면 행 순서를 제외하고 비교
- 재시도: 가드레일, 의미 검증 또는 DB 실행 실패 시 오류 피드백을 넣어 1회 재생성

평가 범위에는 매출, 계약, 직원·연봉, 고객사, 프로젝트, 지원 티켓, 제품 질의가 포함된다. 분기·연도·지역·카테고리·상태·규모 필터, 집계, JOIN, 상위 N개, 코드값 매핑과 의미 혼동 방지 사례를 함께 검증했다.
